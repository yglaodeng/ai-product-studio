# Roadmap

## Near term

- Add a fully synthetic walkthrough from task draft to verified result delivery.
- Improve first-run diagnostics for project registration and collaboration targets.
- Document failure, retry, and blocked-state behavior with reproducible fixtures.

## Later

- Define provider-neutral adapter contracts for additional AI assistants.
- Expand audit exports without exposing conversation or local-machine state.
- Evaluate resumable workflows across documented approval checkpoints.

## Out of scope for the public prototype

- Background execution without explicit user authorization.
- Publishing browser sessions, cookies, conversation URLs, or local paths.
- Dispatching tasks to unregistered projects.
- Claiming integrations that have not passed provider-side verification.
